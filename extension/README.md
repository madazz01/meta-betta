# Meta Betta

A friendly VS Code workmate for Muse Code that remembers you and your project.

## Install

You need [Muse Code](https://docs.meta.ai) installed, plus an API key. Then install this extension and open the Meta Betta view.

## First run

The first time the panel opens in a folder, it walks you through three quick steps: finding Muse, connecting, and pasting your API key. Your key stays in your machine's secret store — never in a file. Then it runs a tiny test turn so you know everything works.

## The brain

Meta Betta keeps a `brain/` folder in your workspace: who you are (`me.md`), what you're building (`project.md`), workarounds that worked (`tricks.md`), and a daily log. It reads the brain at the start of each session, so mornings begin with "here's where we're up to" instead of from zero.

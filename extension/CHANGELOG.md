# Changelog

## 0.1.0 — first public release

- Chat panel for Muse Code: calm bubbles, folded thinking, step groups, copyable replies.
- Brain folder that remembers you and your project across sessions.
- Ask / Auto / All approval modes, with safe steps going through quietly.
- Undo for file changes (with a warning past saved commits), fork a chat to try another way.
- Sidebar: token usage, session list, brain cards. Save my day, quick saves, backups.
- Guided first run: finds Muse, connects, stores your API key, runs a test turn.
